# Security policy

## Reporting a vulnerability

Please report security issues privately, either by email to [security@omnileaf.app](mailto:security@omnileaf.app) or through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for a security problem.

Include what you found, how to reproduce it, and the version or commit you tested. We'll acknowledge the report and keep you updated while we investigate and fix it.

## Supported versions

Omnileaf has no release yet. Once it does, security fixes go into the latest release.
