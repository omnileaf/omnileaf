# Decision records

Each file here records one decision that closes off an alternative: what was decided, why, and what it costs. They explain why the code looks the way it does, so a later change doesn't undo a choice without knowing its reasons.

- **Copy [the template](0000-template.md)** to the next free number, for example `0002-workspace-layout.md`, and fill it in within the same pull request as the change it records.
- **Keep it short.** Context, the decision, its consequences, and one line per rejected alternative.
- **Records are never rewritten once accepted.** A changed decision gets a new record, and the old one's status becomes `Superseded by NNNN`.
