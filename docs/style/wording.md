# Wording

How Omnileaf describes itself in the README, docs, release notes and the app's own text.

- Describe features technically: which formats the app reads, how it syncs, how it caches.
- Never frame the app as a way to get content for free, or as a way to read any particular title.
- Don't name other reader apps or third-party websites. Name file formats, protocols and self-hosted servers, such as OPDS, Komga and Kavita, only where they describe a feature.
- Use the generated sample library in examples: "Sample Series 03", "Author A".
- Use reserved example domains: `example.com`, `example.org`, `*.test`, `*.invalid`.

| Avoid | Write instead |
|---|---|
| read for free | read your own files and servers |
| unlimited manga | a fast reader for comics, manga and ebooks |
| supports any site | reads OPDS catalogs and self-hosted servers |
